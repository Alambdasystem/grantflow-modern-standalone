# Flashy Next.js UI Template Recommendation

## Best Fit For This Project

Use a shadcn-based shell plus motion-heavy sections.

Why this fit:
- Works directly in your existing Next.js app (no re-platforming).
- Compatible with your current Tailwind and React Query architecture.
- Lets us add high-polish animated sections quickly while keeping existing routes.

## Install Commands

Run in frontend directory:

```bash
npm run ui:flash:init
npm run ui:flash:add-core
```

## Visual Direction

Recommended style direction:
- Hero and dashboard cards with layered gradients and glass blur.
- Animated metric blocks using Framer Motion.
- Section transitions and staggered reveals.
- Dense, high-contrast data surfaces for grant workflows.

## Optional Premium Layer

If you want an even flashier environment after core install, we can add:
- Aceternity-style animated blocks (spotlights, beams, floating gradients).
- Dashboard page transitions and kinetic side navigation.
- Alternate typography packs and branded token set.

1. Install components and tokens.
